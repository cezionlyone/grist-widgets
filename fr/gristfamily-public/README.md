# Gristfamily

Arbre généalogique pour Grist, édition française aux couleurs de Grist (madeXcé).

- Arbre centré sur une personne : ascendants, descendants, conjoints, fratrie ; bouton « + » sur chaque carte pour ajouter un proche.
- Familles recomposées, demi-frères et sœurs, adoptions, dates approximatives (« vers 1920 »).
- Vues Ascendance (éventail), Liste triable, Anniversaires, Carte des lieux (vivants et ancêtres), Cousins ADN, Prénoms transmis, Recherches (suggestions calculées depuis l'arbre).
- Fiche détaillée avec fil de vie, documents joints, notes et sources.
- Création des tables et paramétrage depuis le widget, aide intégrée, utilisable sur téléphone et tablette.

## Installation

1. Dans votre document Grist, ajoutez une vue « Personnalisée ».
2. Collez l'adresse : `https://cezionlyone.github.io/grist-widgets/fr/gristfamily-public/`
3. Dans le panneau de droite, rubrique « Accès », choisissez « Accès complet au document ».
4. Suivez l'assistant : il crée les tables nécessaires ou se relie à vos propres tables.

## Vie privée

Vos données restent dans votre document Grist. Seuls les noms de lieux (jamais ceux des personnes) sont envoyés au service de cartographie OpenStreetMap pour être placés sur la carte.
