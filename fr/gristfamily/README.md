# Gristfamily

Arbre généalogique pour Grist, édition française aux couleurs de Grist (madeXcé).

- Arbre centré sur une personne : ascendants, descendants, conjoints, fratrie ; bouton « + » sur chaque carte pour ajouter un proche.
- Familles recomposées, demi-frères et sœurs, adoptions, dates approximatives (« vers 1920 »).
- Vues Ascendance (éventail), Liste, Anniversaires, Carte, Cousins ADN (copier-coller ou import groupé depuis MyHeritage).
- Création des tables et paramétrage depuis le widget, panneau d'aide, utilisable sur téléphone et tablette.

Adresse à coller dans Grist : `https://cezionlyone.github.io/grist-widgets/fr/gristfamily/`

Dans le panneau de droite de la vue personnalisée, rubrique « Accès », choisissez « Accès complet au document ».
