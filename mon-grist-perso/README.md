# 🎄 Mon Grist perso - calendrier de l'Avent

Un calendrier de l'Avent pédagogique pour Grist, du 1er au 24 décembre 2026. Chaque case s'ouvre le jour venu, à 9 h (heure de Paris) : un widget à installer en un clic, une leçon « Sous le capot », un quiz ou un défi.

Ce dossier est en cours de construction : le contenu des cases sera publié jour après jour.

- `calendrier/` : le calendrier.
- `avent/jour-01/` à `avent/jour-24/` : les cases. Avant leur date, elles affichent une case d'attente avec un compte à rebours.

Le document modèle « Mon Grist perso » sera proposé à la duplication avant le 1er décembre. Il est conçu pour un espace personnel sur Grist Labs (docs.getgrist.com) : ne mettez pas vos données privées sur l'instance de votre employeur.
