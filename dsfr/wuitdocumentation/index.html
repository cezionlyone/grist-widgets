          Comment fonctionne la visite guidée
          
    
          La visite affiche des bulles d'aide étape par étape pour guider les utilisateurs dans votre application. Elle se déclenche automatiquement à la première visite.
          
    
          Pour chaque étape : renseignez un titre, un contenu, la position de la bulle (haut/droite/bas/gauche), et le lien d'ancrage de la cellule cible.
          
    
          Lien d'ancrage : sélectionnez la cellule cible dans votre document, appuyez sur Ctrl+Maj+A (ou Cmd+Maj+A sur Mac), puis collez le lien ici. Supprimez tout ce qui précède /p/ (ex : gardez uniquement /p/8#a1.s21.r1.c39).
          
    
          Activation : tant que le switch est désactivé, la visite ne se déclenche pas. Activez quand votre parcours est prêt.
