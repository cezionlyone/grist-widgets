# grist-widgets

Des widgets personnalisés pour [Grist](https://www.getgrist.com), libres d'utilisation et de modification.

| Widget | Ce qu'il fait | Adresse à coller dans Grist |
|---|---|---|
| [Gristcity](gristcity/) | Dessine une table sous la forme d'une ville en 3D isométrique : chaque ligne devient un immeuble qui se construit au fil de ses étapes. | `https://cezionlyone.github.io/grist-widgets/gristcity/` |

## Utiliser un widget

1. Dans votre document Grist, ajoutez une vue de type **Personnalisée**.
2. Choisissez l'**URL personnalisée** et collez l'adresse du widget.
3. Dans le panneau de droite, rubrique **Accès**, accordez le niveau d'accès demandé par le widget.
